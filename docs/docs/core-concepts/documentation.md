# Documentation

This documentation page is powered by Docusaurus and lives within the `/docs` directory. Although it's part of the projects repo, it runs entirely separate from the rest of the project.

All of the documentation is rendered from plain Markdown files, making it super easy to add or edit documentation. These Markdown files are located within `/docs/docs`, organized by topic. While the documentation server is running, the website will automatically update as changes are saved.

To add a new section (folder within `/docs/docs`) to the site, navigate to `/docs/sidebar.ts` and copy one of the existing categories, replacing the label and directory name.
