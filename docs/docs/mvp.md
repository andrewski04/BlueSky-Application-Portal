# Minimal Viable Product

The BlueSky Application Portal will be a web application that allows admins to create and manage forms for applicants to fill out.

## Core Features

- **Admin**
  - Create and manage forms
  - View and edit form data
  - Manage users and permissions
  - Manage form submissions
  - Sort and filter form submissions

- **Applicant**
  - Fill out forms
  - View form submissions
  - Sort and filter form submissions
